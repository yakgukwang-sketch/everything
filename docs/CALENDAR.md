# Everything 개발 캘린더

> 기준: 2026-03-23 (풀플로우 검증 완료 시점)
> 원칙: 돈이 흐르는 구조부터 완성 → 데이터 → 에이전트 생태계

---

## Week 1: 셀러 경험 완성 (3/24 ~ 3/30)

셀러가 실제로 쓸 수 있는 수준으로.

| 날짜 | 작업 | 상세 |
|------|------|------|
| 3/24 (월) | 셀러 대시보드 개선 | 상품 수정(PATCH) UI, 주문 목록 + 상태 변경 UI |
| 3/25 (화) | 이미지 업로드 | R2 버킷 연동, 상품 등록 시 이미지 첨부 |
| 3/26 (수) | 상품 상세 페이지 | `/products/:id` 퍼블릭 페이지 (구매 버튼 → 체크아웃) |
| 3/27 (목) | 체크아웃 플로우 | 체크아웃 UI 점검 + 에이전트 수수료 표시 개선 |
| 3/28 (금) | 셀러 온보딩 | `/submit` → 셀러 가입 유도, 가입 후 대시보드 리다이렉트 |
| 3/29~30 | 버그 수정 + QA | 전체 플로우 재테스트, 엣지케이스 처리 |

**마일스톤**: 셀러가 가입→상품 등록(이미지 포함)→주문 확인→상태 변경 가능

## Week 2: 데이터 + 크롤링 강화 (3/31 ~ 4/6)

에이전트가 추천할 상품이 많아야 에이전트가 의미 있음.

| 날짜 | 작업 | 상세 |
|------|------|------|
| 3/31 (월) | 크롤러 스케줄링 | 네이버/쿠팡/뽐뿌 자동 실행 (cron 또는 GitHub Actions) |
| 4/1 (화) | 뽐뿌 쇼핑몰 추출 | 뽐뿌 딜 링크에서 한국 주요 쇼핑몰 목록 자동 추출 |
| 4/2 (수) | 새 크롤러 1 | 11번가 or G마켓 (거래량 큰 곳) |
| 4/3 (목) | 새 크롤러 2 | 무신사 or 오늘의집 (카테고리 확장) |
| 4/4 (금) | price_guide 갱신 | 새 데이터 기반 적정가 재계산 + 업로드 |
| 4/5~6 | 데이터 품질 | 중복 제거, 카테고리 정리, 만료 딜 정리 |

**마일스톤**: 10만+ 상품, 크롤러 자동 실행, 5개+ 데이터 소스

## Week 3: 에이전트 생태계 (4/7 ~ 4/13)

다양한 에이전트 = 다양한 소비자 유입.

| 날짜 | 작업 | 상세 |
|------|------|------|
| 4/7 (월) | 에이전트 3~4호 | 뷰티 전문, 가전 전문 (스킬 MD 추가) |
| 4/8 (화) | 에이전트 5~6호 | 선물 추천, 핫딜 스나이퍼 |
| 4/9 (수) | 에이전트 경쟁 UI | 같은 상품에 여러 에이전트 수수료 비교 표시 |
| 4/10 (목) | 에이전트 성과 대시보드 | 쿼리 수, 주문 전환율, 수익 통계 |
| 4/11 (금) | 외부 에이전트 등록 테스트 | 개발자 가입 → API key → 커스텀 에이전트 등록 플로우 |
| 4/12~13 | 에이전트 랭킹 개선 | 실제 주문 전환 기반 랭킹 (쿼리 수만이 아닌) |

**마일스톤**: 6개 에이전트, 외부 개발자 에이전트 등록 가능

## Week 4: 결제 + 런칭 준비 (4/14 ~ 4/20)

실제 돈이 움직이는 구조.

| 날짜 | 작업 | 상세 |
|------|------|------|
| 4/14 (월) | 결제 연동 조사 | 토스페이먼츠 / 포트원 / 카카오페이 비교 |
| 4/15 (화) | 결제 API 연동 | 선택한 PG사 연동 (테스트 모드) |
| 4/16 (수) | 결제 플로우 완성 | 체크아웃 → PG 결제 → 주문 확정 → 셀러 알림 |
| 4/17 (목) | 정산 시스템 설계 | 셀러 정산 + 에이전트 수수료 정산 로직 |
| 4/18 (금) | 커스텀 도메인 | everything.kr 또는 대안 도메인 연결 |
| 4/19~20 | 런칭 QA | 전체 플로우 최종 점검, 성능 테스트 |

**마일스톤**: 실결제 가능, 커스텀 도메인, MVP 런칭 준비 완료
